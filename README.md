# 🛠️ KofileDev GitHub Change Requests

Welcome to the KofileDev GitHub organization. To keep our repositories secure and audit-compliant, all administrative changes must go through our internal ticketing system.

### How to request changes:

#### *Note: You must be a member of the Kofile Microsoft 365 organization.*

Please submit a ticket via our **[GitHub Helpdesk Portal](https://helpdesk.kofile.com/support/catalog/items?category_id=19000258153)** for:

* Creating a new repository
* Being added to a team or changing access rights
* Registering or installing new GitHub Apps
* Adjusting branch protection rules
* Any other GitHub requests

*Standard requests are typically processed within 1 business day.*
